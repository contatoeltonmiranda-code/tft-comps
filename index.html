    Vários campeões
    Na busca do topo, separe por vírgula, espaço ou +: “rakan, taric” ou “kog maw sivir”. Aparecem primeiro as comps com todos, depois as que têm parte, com o indicador 2/3 e a fase onde cada um está. Os chips mostram o que foi reconhecido; o X remove.
    Busca na comp
    O campo dentro de cada comp mostra só os campeões dela que batem com o texto (aceita vários: rakan, taric). A busca do topo continua separada.
    Check no campeão
    Marca “já peguei” (principal e flex). O contador mostra quantos faltam e “Limpar checks desta comp” zera só ela. “Limpar checks” no topo zera todas as comps para a próxima partida.

    Dados

    As comps e os checks ficam salvos só neste navegador (os checks não vão no arquivo exportado). Use Exportar para guardar um arquivo JSON e Importar para trazer de volta.
