Como ligar com as suas partidas (uma vez só)

O pós-jogo usa a API oficial da Riot. Um programa pequeno no seu PC baixa as partidas novas sozinho, sem janela, e guarda tudo só no seu computador. Esta página lê esse arquivo local. A chave da Riot nunca sai do seu PC e nunca vai para o GitHub.

  1. Entre no portal da Riot em developer.riotgames.com com a sua conta da Riot.
  2. Chave de teste (dá para usar hoje). Logo depois de entrar, o portal já mostra uma chave que começa com RGAPI-. Ela vale só 24 horas: amanhã é preciso clicar em “Regenerate API Key” e colar a nova. Serve para ver tudo funcionando.
  3. Chave pessoal (a definitiva). No portal, abra “Register Product”, escolha projeto pessoal e preencha o formulário. A Riot pede uma descrição detalhada do produto; pode colar o texto abaixo. A chave pessoal não expira todo dia, mas só vem depois da aprovação. Limites: 20 chamadas por segundo e 100 a cada 2 minutos, e não pode ser usada em produto público. O helper respeita esses limites. 
    Product name: TFT Comps (personal use)
Description: Personal, non-public tool for one player. It downloads only my own Teamfight Tactics match history through tft-match-v1 and account-v1 (by Riot ID), a few requests every 15 minutes, and stores it only on my own PC. A local page then shows my average placement and a post-game review of each match (final board, comp, level and elimination round). It also shows a static pre-game plan. It has no public users, no overlay, no screen capture, no memory reading, no real-time data from a game in progress, and no augment or Legend win rates.
Type: personal project (not for public consumption).
  4. Rode o setup no PC (ele pergunta o seu Riot ID, no formato nome#tag, e a chave; a chave não aparece na tela): node tools/riot-setup.js
  5. Instale as tarefas ocultas (buscam partidas novas a cada 15 minutos e ligam o servidor local quando você entra no Windows; nunca abrem janela): powershell -ExecutionPolicy Bypass -File tools\riot-instalar.ps1 -Iniciar
  6. Abra esta página. Se o navegador perguntar sobre acesso à rede local ou ao “localhost”, escolha Permitir. Se continuar bloqueado (acontece no Brave), use o botão “Importar partidas.json”: o arquivo fica em %LOCALAPPDATA%\tft-comps\partidas.json.

Para desligar tudo: powershell -ExecutionPolicy Bypass -File tools\riot-remover.ps1
